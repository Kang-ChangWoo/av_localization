# analysis/

One folder per experiment, each self-contained: `src/` computes, `data/` holds
every number, `md/<name>.md` holds the tables (a block regenerated by the
script) followed by a reading written by hand, `figs/` the figures. Every
experiment reads the test tables of the headline protocol (projection trained
on the benchmark's own training rooms, fixed structure, three scalars chosen
on validation rooms, test rooms evaluated once) and shares the loader in
`common.py`.

| folder | question |
|---|---|
| `exp1_computational_resource` | what the method costs: parameters, time per query, cost per building |
| `exp2_plausible_poses` | does acoustic verification resolve visual ambiguity? by number of plausible poses, and which one gets picked |
| `exp3_top2_disambiguation` | can acoustics separate the two places vision confuses most? |
| `exp4_formulation` | why verification rather than acoustic localization: candidate-set size and oracle |
| `exp5_ablation` | projection source, rule, beyond-shortlist variants, the cell-product rule, transfer matrix |
| `exp6_robustness` | a degrading camera with everything frozen, and whether collapse can be detected |

The earlier `run_analysis.py` / `beyond_fov.py` blocks (collection-split
protocol, unprojected feature) are superseded by these and were removed; the
beyond-field-of-view question is recorded as a null result in
`../feasible/README.md` (item O).
