## A note on the scripts

Every script under `scripts/` is referenced by at least one document, usually
`decision_log.md`, as the exact command that produced a number. None of them
have been moved or deleted during tidying for that reason: a documented command
that no longer resolves is a broken result, not a tidy repository. Scripts
superseded by later work are still listed in the log entry that used them.
